# Changelog

All notable user-visible changes to the Backrest TOS application package.

## 1.14.1-1 — 2026-11-14

### Added
- First release. Backrest (`garethgeorge/backrest:v1.14.1`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8055 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/backrestdocker/`.
